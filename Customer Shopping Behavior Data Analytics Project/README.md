# Customer Shopping Behavior Analysis
 
End-to-end data analysis project exploring customer shopping behavior — from raw CSV data, through Python-based cleaning and PostgreSQL loading, to SQL-driven business analysis and an interactive Power BI dashboard.
 
## Overview
 
This project analyzes a retail customer shopping dataset (~3,900 transactions, 18 attributes) to answer key business questions around revenue drivers, customer segmentation, discount behavior, and subscription value. The workflow moves data from a flat CSV file into a relational database, applies SQL for analysis, and visualizes the results in an interactive dashboard.
 
## Dataset
 
`customer_shopping_behavior.csv` — ~3,900 customer transaction records with the following attributes:
 
- Customer demographics: `Age`, `Gender`, `Location`
- Purchase details: `Item Purchased`, `Category`, `Purchase Amount (USD)`, `Size`, `Color`, `Season`
- Engagement: `Review Rating`, `Subscription Status`, `Previous Purchases`, `Frequency of Purchases`
- Transaction attributes: `Shipping Type`, `Discount Applied`, `Promo Code Used`, `Payment Method`

## Methodology
 
1. **Data cleaning & preparation (Python/pandas)**
   - Loaded the raw CSV and inspected structure, types, and missing values
   - Imputed missing `Review Rating` values using the median rating within each product `Category`
   - Standardized column names (lowercase, underscores)
   - Engineered new features:
     - `age_group` — quartile-based bucketing of `age` into Young Adult / Adult / Middle-aged / Senior
     - `purchase_frequency_days` — mapped categorical purchase frequency (e.g., Weekly, Monthly) to numeric day intervals
   - Removed the redundant `promo_code_used` column after confirming it was identical to `discount_applied`
2. **Database loading**
   - Loaded the cleaned DataFrame into a PostgreSQL database using SQLAlchemy/psycopg2
3. **SQL analysis**
   - Queried the PostgreSQL database to answer the business questions below
4. **Visualization**
   - Built an interactive Power BI dashboard on the cleaned data for exploratory and stakeholder-facing analysis
## Business Questions Answered
 
1. Total revenue generated by male vs. female customers
2. Customers who used a discount but still spent above the average purchase amount
3. Top 5 products by average review rating
4. Average purchase amount: Standard vs. Express shipping
5. Spending comparison between subscribed and non-subscribed customers (average spend and total revenue)
6. Top 5 products by discount usage rate
7. Customer segmentation (New / Returning / Loyal) based on purchase history, with segment counts
8. Top 3 most-purchased products within each category
9. Subscription likelihood among repeat buyers (more than 5 previous purchases)
10. Revenue contribution by age group
