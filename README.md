# Personal-Project-Data
## Netflix Data Analysis & Engagement Metrics
A data analysis project performing exploratory analysis, metric calculations, and visualization on Netflix content using Python and Pandas.

## Project Overview
This project analyzes Netflix original titles and engagement data to uncover insights into viewer habits, content popularity, rating dynamics, and platform trends over time.

## Key Features & Highlights
Data Cleaning & Wrangling: Processes datasets using Pandas, handling missing values, converting temporal variables, and mapping numerical and categorical features.

Content & Genre Insights: Categorizes movies and TV shows across different genres to highlight content distribution.

Rating & Score Metrics: Evaluates title performance using review metrics, IMDb-style scores, and vote distributions.

Statistical Visualizations: Generates dynamic plots and visual data distributions to convey engagement trends effectively.
